# REST API v1

Base path: `/api/v1`

Planned resource groups:

- /auth
- /users
- /customers
- /vehicles
- /cases
- /cases/{id}/photos
- /cases/{id}/damages
- /estimates
- /estimates/{id}/lines
- /estimates/{id}/pdf
- /estimates/{id}/approve
- /work-orders
- /settings
- /audit

## API principles

- JSON over HTTPS
- Tenant context required for tenant-owned resources
- UUID resource identifiers
- Explicit pagination
- Validation through Pydantic schemas
- Stable error envelope
- Idempotency for selected create/transition operations
- Optimistic concurrency for editable estimates

## Fleet contracts and invoicing (release 2)

| Method | Path | Permission | Notes |
| --- | --- | --- | --- |
| GET | `/contracts?customer_id=&active_only=` | customer.read | List contracts with customer name |
| GET | `/contracts/active?customer_id=` | customer.read | Contract in force today, or `null` |
| POST | `/contracts` | customer.write | Create contract |
| GET/PATCH | `/contracts/{id}` | customer.read / customer.write | Read / update (audited) |
| POST | `/contracts/{id}/fee-invoices` | invoice.create | Body `{period_month: "YYYY-MM"}`; one invoice per period |
| GET | `/estimates?q=&status=&repair_case_id=` | estimate.read | Includes case, plate, customer, contract name |
| PATCH | `/estimates/{id}/pricing` | estimate.change_price | Body `{apply_contract: bool}`; reprices all lines |
| GET | `/work-orders?q=&status=&open_only=` | work_order.read | Includes plate, fleet number, customer, request |
| GET | `/invoices?q=&status=&kind=&customer_id=` | invoice.read | `kind` = `REPAIR` or `CONTRACT_FEE` |
| GET/PATCH | `/invoices/{id}` | invoice.read / invoice.create | Detail with lines; edit dates, payment method, notes |
| PATCH | `/invoices/{id}/status` | invoice.create | DRAFT→ISSUED/CANCELLED, ISSUED→PAID/CANCELLED, PAID→ISSUED |
| GET | `/invoices/{id}/pdf` | invoice.read | Courtesy PDF |
| GET | `/invoices/{id}/fatturapa` | invoice.read | FatturaPA FPR12 XML; 422 lists missing data |
| GET/PUT | `/settings/company` | settings.manage | Workshop fiscal identity |

Estimate pricing terms (`labor_included`, `labor_discount_percent`, `parts_markup_percent`) are copied from
the contract when the estimate is created, so later contract changes never alter existing estimates.
